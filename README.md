# Pokédex

Pokédex interativa desenvolvida com JavaScript e integrada à [PokéAPI](https://pokeapi.co/).

[![Abrir projeto](https://img.shields.io/badge/Abrir_projeto-EF5350?style=for-the-badge&logo=googlechrome&logoColor=white)](https://marcosloll.github.io/Pokedex/)
[![Código](https://img.shields.io/badge/Ver_código-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/marcosloll/Pokedex)

## Funcionalidades

- Pesquisa de Pokémon por nome ou número.
- Navegação pelos botões anterior e próximo.
- Exibição do nome, número e sprite do Pokémon.
- Uso de sprites animados com imagens alternativas quando necessário.
- Mensagem amigável quando o Pokémon não é encontrado.

## Executar localmente

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` com o Live Server ou diretamente no navegador.

A consulta dos Pokémon requer conexão com a internet.
